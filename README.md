# Clínica Dental Landa — Landing Page

A responsive landing page for a fictional dental clinic, developed as a practice and portfolio project.

The project focuses on creating a professional website for a local business, featuring service details, testimonials, calls to action, and a functional contact form.

 ## Features
* Responsive design for mobile devices, tablets, and desktop.
* Responsive navigation menu using Bootstrap.
* Hero section with a call to action.
* Service showcase.
* Patient testimonials.
* Contact form with validation.
* Visually identified required fields.
* WhatsApp form integration.
* Social media links.
* Custom CSS design.
* JavaScript separated from HTML.
* Deployed via GitHub Pages.

## Technologies Used
* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Bootstrap Icons
* Google Fonts
* Git & GitHub
* GitHub Pages
 
## Key Functionality

The contact form captures basic user data and automatically generates a WhatsApp message containing the provided information.

It does not use a backend or database; communication takes place directly via WhatsApp.

## Project Objective

This project is part of my practice in developing functional, responsive landing pages for businesses and ventures.

The goal is to work on various types of landing pages, starting with lead-generation sites and later exploring pages focused on products and conversion.

## Demo Project

Clínica Dental Landa is a fictional brand created solely for practice and portfolio purposes.

The contact details, testimonials, professional information, location, and other content used on this landing page are fictional and do not represent a real business.

#  Clínica Dental Landa — Landing Page
